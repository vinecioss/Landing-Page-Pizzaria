# Pizzaria Delícia - Landing Page

Projeto da disciplina de TADS - Desafio 1 (HTML5 + CSS3).

## Como rodar

Só abrir o `index.html` no navegador.

## Imagens

Faltam adicionar as imagens em `assets/img/`:

- `pizza.jpg` - imagem de fundo da hero section
- `cliente-joao.jpg` - foto do cliente no depoimento
- `logo.png` - caso queira trocar o logo em texto por uma logo de verdade

Sem essas imagens a página funciona normal, só fica sem a foto de fundo e sem a foto do cliente.

## Estrutura

- `index.html` - página principal
- `obrigado.html` - página de agradecimento (abre depois de enviar o formulário)
- `style.css` - estilos de tudo
- `assets/img` - imagens

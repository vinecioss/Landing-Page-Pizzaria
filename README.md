# Pizzaria Delícia - Landing Page

Projeto da disciplina de TADS - Desafio 1 (HTML5 + CSS3) e Desafio 2 (JavaScript + deploy).

## Como rodar

Só abrir o `index.html` no navegador.

## Estrutura

- `index.html` - página principal
- `obrigado.html` - página de agradecimento (abre depois de enviar o formulário)
- `style.css` - estilos de tudo
- `js/scripts.js` - interatividade (carrossel de depoimentos e validação do formulário)
- `assets/img` - imagens

## Desafio 2

- Carrossel de depoimentos: os botões "Anterior" e "Próximo" trocam o depoimento mostrado (feito só com JS puro, sem framework).
- Validação do formulário: antes de enviar, o JS confere se os campos obrigatórios foram preenchidos, se o telefone é válido, se um sabor foi escolhido e se uma forma de pagamento foi marcada. Se estiver tudo certo, redireciona pra `obrigado.html`.
- Deploy: https://landing-page-pizzaria-rust.vercel.app
